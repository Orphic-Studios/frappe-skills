# Windsurf (Codeium Cascade) Integration

Windsurf uses `.windsurfrules` at the root of a workspace to configure AI behavioral rules and domain expertise.

---

## 🚀 Setup

Copy `.windsurfrules` to the root of your project:
```bash
cp adapters/windsurf/.windsurfrules /path/to/your/project/.windsurfrules
```
