# GitHub Copilot Integration

GitHub Copilot automatically loads custom instructions placed in `.github/copilot-instructions.md`.

---

## 🚀 Setup

Copy `copilot-instructions.md` into your repository's `.github/` folder:
```bash
mkdir -p .github
cp adapters/copilot/copilot-instructions.md .github/copilot-instructions.md
```
