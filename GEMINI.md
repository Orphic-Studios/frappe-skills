# GEMINI.md — Frappe Skills Pack Configuration for Gemini CLI & Antigravity

This repository bundles production-grade Frappe Framework & ERPNext skills (`skills/`), agent personas (`agents/`), and slash commands (`.gemini/commands/` & `commands/`).

## Skills & References

- **`skills/frappe-docs/SKILL.md`**: Complete technical knowledge base covering Frappe Framework (architecture, Python ORM, DocType system, hooks, REST/JS APIs, bench CLI), ERPNext modules, ecosystem apps, and 40+ troubleshooting guides.
- **`skills/frappe-course-generator/SKILL.md`**: Automated instructional engine for generating Arabic training courses with English code, exercises, quizzes, and PDF/PPTX/ZIP export scripts.
- **`references/`**: Standing checklists (`doctype-checklist.md`, `security-checklist.md`, `course-quality-checklist.md`).

## Commands

- `/frappe-ask` — Answer technical questions or implement features in Frappe & ERPNext
- `/frappe-doctype` — Design and scaffold a DocType, controller, client script, hooks, and tests
- `/frappe-debug` — Diagnose and fix Frappe, ERPNext, bench, MariaDB, or Redis errors
- `/frappe-course` — Generate a complete Arabic training course or module
